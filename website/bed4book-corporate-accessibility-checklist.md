# Corporate UI implementation checklist
- [ ] Preserve the approved BED4BOOK logo, red 4 and brand slogan.
- [ ] Verify mobile and desktop navigation with keyboard and screen reader.
- [ ] Ensure visible focus, sufficient contrast and reduced-motion support.
- [ ] Test contact links and responsive overflow.
- [ ] Run web build and browser E2E before merging.
- [ ] Keep the corporate deployment isolated from the B2B API.
- [ ] Obtain explicit approval before any live deployment.
