# BED4BOOK Kurumsal Web Sitesi

Bu alan `b2b.bed4book.com` rezervasyon uygulamasından ayrı kurumsal web sitesi için ayrılmıştır.

## Tasarım referansları

Kullanıcının yükleyeceği görseller temel alınarak sayfa tasarımı oluşturulacaktır. Henüz görsel yüklenmedi; örnek tasarım nihai değildir.

- `assets/references/`: kullanıcıdan gelen tasarım örnekleri
- `assets/images/`: kullanılacak onaylı görseller
- `index.html`: kurumsal web sitesi ana sayfası (tasarım sonrası)

Kurumsal kimlik: koyu antrasit/siyah, kırmızı, beyaz. Onaylı BED4BOOK logosu değiştirilmez.

Bu dalın oluşturulması Railway yayın ayarlarını değiştirmez.
